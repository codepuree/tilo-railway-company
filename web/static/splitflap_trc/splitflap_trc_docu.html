Splitflap Display System Documentation

1. Architecture Overview

This system simulates a mechanical Japanese Splitflap Board (Solari-style). It consists of three main pillars:

  • Python (Flask): The Controller. Manages the logic, train queues, and real-time updates.
  • JavaScript (ES6): The Engine. Handles animations, character rendering, and communication.
  • CSS3: The Visuals. Defines the flip-mechanic, colors, and typography.

2. Python Test Environment (splitflap_trc_app)

The Python module provides a web-based dashboard to control two rows of flaps simultaneously.

Usage Instructions

  1. Run python splitflap_trc_app in your project directory.
  2. Access the dashboard via http://localhost:8080.
  3. Use the "NEXT TRAIN" button to trigger the sequence logic.

Automatic Queue Logic

The controller follows a specific "Shift-Up" logic typical for train stations:

  • Empty Board: The first train goes to Row 1 (Top).
  • Row 1 occupied: The next train goes to Row 2 (Bottom).
  • Both occupied: Row 2's data is pushed to Row 1, and a new train is generated for Row 2.

3. Communication (PostMessage)

To avoid the "black screen" flicker during updates, the system uses the postMessage API instead of URL refreshes.
